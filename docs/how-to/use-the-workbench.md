# 使用工作台

工作台是 `seesea` 自带的一个网页：在浏览器里搜索、读网页、看来源状态，也能从它启动 HTTP 接口和远程 MCP 服务。

## 打开

```bash
seesea desk
```

命令会打开浏览器，地址是 `http://127.0.0.1:7878/`。不想自动打开时加 `--no-open`。工作台只监听回环地址，不要密钥；它管理的是这台机器。

页面也由 `seesea serve` 在 `/` 提供，用来远程查看一台服务器。这时没有“服务”和“账号”两页，页面会在需要时向你要 API 密钥，只存在当前标签页里。

## 搜索和标注

1. 在搜索框输入查询，选 `快`、`标准` 或 `深`，按回车。
2. 顶部的色条按阶段显示耗时。黄字是降级说明，红字是失败的来源。
3. 点“详情”看分数怎么构成、读到了哪些章节、同一事件的其他报道。
4. 点“好”或“差”告诉第一层排序这个主机的好坏。这需要根密钥；在本机工作台里无需密钥即可使用。

键盘：`/` 聚焦搜索框，`j` 和 `k` 选择结果，`d` 展开详情，`g` 和 `b` 标好坏，`o` 打开链接，`Ctrl K` 打开命令面板。

## 复盘和打分

“复盘”页汇总最近的搜索日志：哪些来源失败、哪些主机读不到、哪些搜索值得再看（点“再搜一次”会带着查询回到搜索页），以及第一层排序学到的主机评分。

下面按查询列出当时的前十个结果。给每个结果点 0 到 3：3 正是想要的，2 回答了问题，1 相关，0 无关。点已选的分数取消。每次点击都会写入标注文件，页面底部给出文件路径和评估命令：

```bash
seesea eval <标注文件>
```

改过排序设置之后用同一个文件再评估一次，就能比较前后的得分。

## 启动 HTTP 接口

1. 打开“服务”页，在“HTTP 接口”卡片里选监听地址和认证方式。
2. 只在本机用，保持 `127.0.0.1:8080` 和“不要密钥”。要给别的机器用，把地址改成 `0.0.0.0:8080`，选一个共享密钥或账号认证，并填 TLS 证书和私钥；前面已有终止 TLS 的反向代理时，勾选对应选项。
3. 点“启动”。卡片下方会出现可复制的 `curl` 命令。
4. 勾选“随工作台启动”后，下次打开工作台时它自动启动。

非本机地址没有 TLS 和密钥时，启动会被拒绝，页面显示原因。

## 启动远程 MCP

“远程 MCP”卡片和上面一样，但只提供 `/mcp`，不暴露搜索接口以外的任何东西。默认地址是 `127.0.0.1:8090`。

1. 认证方式选“一个共享密钥”，点“启动”。密钥自动生成，可以显示、复制、换新。
2. 卡片下方给出 Claude Code 的 `claude mcp add` 命令和通用的 `mcp.json` 片段，复制进客户端即可。
3. 要让别的机器上的客户端连接，把地址改成 `0.0.0.0:8090`，并配好 TLS。

改了设置后点“应用并重启”才会生效；已经建立的请求会先处理完。

## 管理账号

“账号”页添加用户、发密钥、停用用户、吊销密钥。新密钥只显示一次。服务的认证方式选“账号里的密钥”或“两者都行”时，这里的用户才有用。认证选“账号”但还没有任何用户时，服务不会启动。

设置保存在数据目录的 `desk.json` 里，只有当前用户可读，因为它可能包含共享密钥。
